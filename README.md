# DataScienceML-Movie-Portfolio-Project

## The Plan 
To not only answer the research questions, but to also deploy a GitHub hosted website to better display and visualize my findings to showcase to my peers and possible employers.

## Data Sourcing & Collection 
Rather than downloading a pre-made data set from a source like Kaggle, the idea is to build my own master dataset of movies from multiple sources using a combination of API's (TMDB API, IMDb). In doing so, I can have more control over the dataset itself while also getting a better understanding of the full process of data analytics. 

Varying data regarding each movie can be found in multiple sources. For instance, the movie genre, release date, budget, revenue, runtime, cast, and production may all be found in the TMDB API, whilst ratings can be found via IMDb-related data. 

## Questions to Answer 

The following is subject to change: \
How much of an impact does a movies budget have on its performance? \
Can previous movie data be used to predict the outcome of upcoming movies? \
What movie attributes have the greatest impact on box-office performance? \
What movies achieve unexpected performance? \
How does release time affect box office performance? \
Can we predict if a movie will be a box office hit or flop? \
How do studios, genres, casts, and characters influence movie performance? \
Can we identify common characteristics among high-performing movies?  \
Can we identify common characteristics among low-performing movies? \
Can studio, genre, cast, budget, ratings, and franchise history collectively be used to predict movie performance? \
Can movies be grouped into distinct performance categories based on their attributes?
